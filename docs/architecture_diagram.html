CentreWatch AI — System Architecture

Privacy-Preserving, Low-Bandwidth Edge AI Monitoring Platform for Distributed PMKVY Training Centres
🔒 Zero Biometrics (DPDP 2023)
📶 <2 KB/min Telemetry
💾 Local SQLite Spool Buffer

Tier 1: On-Premise Edge Device
Training Centre Edge Daemon
Local Mini-PC
🎥 CCTV / IP Video Ingestion RTSP / OpenCV
Standard classroom cameras. Threaded capture drops stagnant frames to guarantee zero buffer latency.
🧠 Dual Edge Vision Models DEIM / YOLOv8
DEIM (CVPR 2025 Real-Time DETR) with 300 bipartite matching query decoders (NMS-free) + YOLOv8-Pose.
📍 Anonymous Motion Tracking ByteTrack Logic
Assigns temporary technical IDs across frames. Zero facial identity profiling.
⏱️ Classroom ROI Dwell Engine Ray-Casting Poly
Requires dwell ≥ 180 seconds within calibrated polygon boundary; ignores hallway passersby.
🛡️ DPDP Act Privacy Masking Gaussian 31x31
Upper 35% of trainee boxes (face area) is blurred at the edge before any visual frame is stored.

Tier 2: Network Gateway
Resilient Transport Pipeline
2G/3G/4G Aware
📶 Telemetry-Only Stream JSON REST
Continuous video never leaves the site. Lightweight JSON telemetry (counts, timestamps) is sent at ≈1.8 KB/min.
⚡ Bandwidth Footprint 99.8% Saved
Cuts data requirements from 2 Mbps (raw 1080p stream) to <2 KB/min, making rural deployment affordable.
💾 Offline SQLite Spool edge/spool.db
During rural network dropouts, telemetry is buffered locally in an edge SQLite queue.
🔄 Recovery Batch Auto-Sync FIFO Batch
On reconnection, events are flushed in chronological order with zero telemetry data loss.
➔
HTTPS REST
Tier 3: Government Cloud
Central Backend Engine
FastAPI & PostgreSQL
🏛️ Digital Twin Registry SQLAlchemy ORM
Maintains national database of centres, rooms, sanctioned quotas (computers, workbenches), and rosters.
⚖️ Compliance Reconciliation ±15% Tolerance
Reconciles reported vs observed: NORMAL (≤15%), REVIEW (16-25%), HIGH (26-45%), CRITICAL (>45%).
🔔 Alert Engine & Deduplication In-Memory Dedup
Prevents notification storms by aggregating repeated observations into singular actionable incident cases.
📡 WebSocket Live Push FastAPI WSS
Broadcasts confirmed discrepancy alerts instantly to command dashboards without client polling.
🚨 SLA Auto-Escalation Daemon / 24h
Unadjudicated critical alerts older than 24h automatically escalate to the State Vigilance Directorate.
